# The Chronicles · Lite

Juego de lectura para primaria con Scholastic Literacy Pro. Cada salón pelea contra su propio jefe leyendo y haciendo quizzes.

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio nuevo y público en GitHub (por ejemplo `chronicles-lite`).
2. Sube **todo el contenido de esta carpeta**: `index.html`, `README.md`, `.nojekyll` y la carpeta `assets` completa.
3. En el repositorio ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/chronicles-lite/`.

## Cómo lo usan las maestras
- Abren el enlace en **Safari** del iPad → **Compartir** → **Agregar a pantalla de inicio**.
- No necesitan cuenta. Todo se guarda en ese iPad, dentro de Safari.
- Cada viernes: bajan el reporte de quizzes de Literacy Pro a **Archivos**, entran a **Import quizzes**, y luego tocan **⚔ HIT** en el proyector.
- Importante: si se borran los datos de Safari, se pierde el progreso. Usen **Settings → Download backup** cada pocas semanas.
